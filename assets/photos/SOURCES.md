# Greeting card photo sources

Every card in `birthday/`, `juma/` and `aralash/` was composed from a photo released as **CC0** or marked **Public Domain**
(found via the Openverse API), with greeting text typeset on top using SIL Open Font License fonts
(Great Vibes, Lobster, Playfair Display, Montserrat, Caveat). No attribution is required; it is kept here for provenance.
